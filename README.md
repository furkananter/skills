# Furkan Anter's Agent Skills

This is a collection of open Agent Skills.

## Repository structure

```text
skills/
├── README.md
├── LICENSE
└── skills/
    └── overengineer/
        └── SKILL.md
```

## overengineer

Prevents overengineering and scope creep while preserving correctness, safety, and maintainability.

```sh
npx skills add furkananter/skills@overengineer
npx skills add furkananter/skills@overengineer -g -y
```

Follows the open [Agent Skills specification](https://agentskills.io/specification).
